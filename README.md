## 📌 Executive Summary

A lightweight, responsive React front-end application built with Vite and TailwindCSS that integrates with OpenAI's DALL-E API. Users can input text prompts to generate high-resolution, AI-synthesized imagery rendered seamlessly within the browser window.

## 🛠️ Technology Stack

* **Front-End Framework:** React 18, Vite
* **API Integration:** OpenAI REST API (DALL-E 3 / DALL-E 2)
* **Styling:** Tailwind CSS / CSS Modules
* **Environment Management:** Vite Environment Variables (`import.meta.env`)
