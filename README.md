## 📌 Executive Summary

A fast, responsive React front-end application built with Vite that interfaces with **Pollinations AI** image generation endpoints. Users can input custom creative text prompts to synthesize and render high-resolution AI imagery in real-time without requiring API key configuration or client-side billing.

---

## ✨ Features

* ⚡ **Instant Image Synthesis:** Generates high-quality AI images on-demand.
* 🛡️ **Zero API Keys Needed:** Operates cleanly without client-side secrets or sensitive `.env` exposures.
* 📱 **Responsive UI:** Modern centered layout optimized for mobile and desktop viewports.
* 🔄 **Dynamic Error & Load Handling:** Real-time visual state management for pending requests and failed server loads.

---

## 🛠️ Technology Stack

* **Front-End Framework:** React 18
* **Build Tool:** Vite
* **API Integration:** Pollinations.ai REST Endpoint
* **Styling:** CSS3 (Flexbox, Dark Mode Theme)

## ⚙️ Quick Start (Local Setup)

### 1. Clone Repository & Install Dependencies
```bash
git clone [https://github.com/Atharva11022/GPTCLONE.git](https://github.com/Atharva11022/GPTCLONE.git)
cd GPTCLONE
npm install

```

### 2. Run Local Development Server

```bash
npm run dev

```

Open `http://localhost:5173` in your browser to view the app!

```
